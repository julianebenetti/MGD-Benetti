🤖 Divulgador automático

Nos horários escolhidos, o PostZap busca ofertas na Shopee (mesma API do MCP), aplica os filtros (comissão mínima R$ 9, nunca suplementos, sem repetir) e manda os melhores para o grupo FILA POST ZAP, cada um como 📌 Post #N — com o seu link de afiliado e a chamada prontos.
